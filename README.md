# منظومة التحكم – شركة الطود | تطبيق الموقع

Android field progress reporting app. Offline local data on device. This test build is not connected to the company's SQL Server and does not enforce server-side user permissions.

Build APK using GitHub Actions > Build ALTOUD Android APK. After a successful run, download the artifact `ALTOUD-Field-Android-APK` and install the contained `app-debug.apk` on Android.
